# Screenshots

Drop product screenshots here using the exact filenames below — the gallery in
the top-level [`README.md`](../../README.md) links to them, so they appear as
soon as you add the files (no README edit needed).

| Filename | What to capture |
|---|---|
| `dashboard.png` | Home dashboard — month spend, budget, loans card, top categories, recent. |
| `expenses.png` | Expenses list. |
| `add-expense.png` | Add/edit expense — amount, category picker, account. |
| `reports.png` | Reports — monthly/yearly with the category breakdown. |
| `categories.png` | Categories screen showing a parent with its subcategories. |
| `sms-capture.png` | SMS confirm dialog (the detected-expense screen). |

## Tips
- **Portrait** phone frames look best for the mobile shots; ~1080×2280 (or any 9:19.5) is fine — the README renders them at 240px wide.
- Use **light theme** for consistency (or add `-dark` variants later).
- PNG preferred; keep each file under ~500 KB if you can (crop/scale before committing).
- To capture on Android: `adb exec-out screencap -p > dashboard.png`.
- For desktop (Electron): use your OS screenshot tool on the app window.

Add more shots if useful (e.g. `loans.png`, `planned.png`, `dark-dashboard.png`)
and link them in the README gallery table.
